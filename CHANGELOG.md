# Changelog

0.6.1: the argument after a CLI flag is its value even when it starts with `-`, and the contract states npm's banner lines before the result line. District names stay final once the batches start, charter motifs that use a banned word are dropped, and a blank model is invalid in the params schema. Name pools are checked for walks through the alphabet with gaps and a swapped pair, and names such as Ng count as sayable. Naming prompts say in plain words what each parcel kind is and ask for founders' family names; the typing prompt asks for given and family names from the same cultures and past each culture's most common names. `npm run build` starts from an empty `dist/`.

0.6.0: the CLI runs from the build and is ready to be called from Compose: strict per-command flags, paths relative to the caller, blank environment values read as unset, one result line on stdout, progress lines and clear errors naming the file, endpoint or cause on stderr. The naming charter is structured (voice, registers, motifs, banned words) and each batch gets its own turn of the motifs; every name is written after its origin. Batches mix a topic's kinds. Repair rounds run batched and fanned out for the districts and for the rest, and also rename names with charter-banned or overused words, or parcels that copy a district or station name, when a clean replacement comes back. Unreadable answers are asked again, provider calls ride out about 90 s of server trouble, and the typing pass repairs name pools that walk the alphabet or hold unsayable names.

0.5.1: each suite proves one contract promise per case through the library and CLI entry points, from one shared test fixture.

0.5.0: named worlds are validated by schema for structure and metadata and in code for selected-name coverage. The named copy is built and patched in one pass, and named JSON is written compact. Naming batches run four at a time carrying a bounded window of taken names, and a busy or dropped provider call is retried.

0.4.10: naming and NPC typing with validated parameters, repairable model output, streamed provider responses, business export and world-folder calls. Agent skill and isolated contract tests cover the public API.
